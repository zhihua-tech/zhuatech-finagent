| GET | `/api/shopfloor/dashboard` | 会计工作台 |
| POST | `/api/shopfloor/work-orders/{id}/reports` | 提交核验结果 |
| POST | `/api/shopfloor/agent-preview` | 运行本地财务演示智能体 |
